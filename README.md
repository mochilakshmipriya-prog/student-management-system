# Student Management System

A simple Student Management System developed using Python and SQLite.

## Features
- Add student details
- View student records
- Store student information in a database
- Manage student records

## Technologies Used
- Python
- SQLite

## How to Run
1. Install Python on your computer.
2. Open the project in VS Code.
3. Run the Python file.

## Purpose
This project helps users store and manage student information easily.
